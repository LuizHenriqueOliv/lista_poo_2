# Questão 2

## a) Informações relevantes para representar um livro

Algumas informações relevantes seriam:

- ISBN;
- título;
- autor;
- editora;
- ano de publicação;
- gênero;
- quantidade disponível.

## b) Por que a classe `Livro` seria uma abstração?

A classe `Livro` seria uma abstração porque representa, dentro do programa, as características e comportamentos importantes de um livro real para o sistema de biblioteca, sem precisar representar todos os detalhes de um livro físico.

## c) Métodos que poderiam existir na classe

Alguns métodos seriam:

- `emprestar()` — realiza o empréstimo do livro;
- `devolver()` — registra a devolução do livro;
- `exibirInfo()` — exibe as informações do livro;
- `estaDisponivel()` — verifica se o livro está disponível.
